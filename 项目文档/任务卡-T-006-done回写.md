# 【T-006】 done 命令（回写画像）

## 任务边界

- 所属模块：[[模块-知识画像]]（回写）、[[模块-任务生成]]（任务闭环）
- 对应需求/验收：[[01-需求与范围确认]] F-04；A-04（状态变「做过」且附产出路径）
- 目标行为：done <知识点> <产出路径> 把该知识点状态升到「做过」，并把产出路径追加进证据；写文件先临时后替换。
- 本任务不做：不改动其他知识点、不删除证据、不做 git 提交、不生成新任务。
- 前置依赖：T-004（已验收）。

## 验收示例

### 正常路径

- 给定：画像里有「列表」（学过）
- 当：python -m src.cli done 列表 tasks/wordcount.py
- 则：状态变「做过」，证据里出现产出路径，其他知识点不动

### 异常或边界路径

- 给定：知识点名不在画像里
- 当：执行 done
- 则：退出码 1，报出该名称并列出可选知识点，画像字节不变
- 给定：少给产出路径
- 当：执行 done
- 则：退出码 2，打印用法

## 实测结论（A-04）

在演示画像（3 已掌握 + 1 存疑）上跑通 M1 的 next → done：

| 步骤 | 结果 |
| --- | --- |
| next | 退出码 0，生成「个人记账小账本」任务并留档 profile/tasks.md |
| done 列表 <产出路径> | 退出码 0；「列表」由「学过」→「做过」，证据 = 原笔记证据 + 「产出：…wordcount.py」 |
| 其他知识点 | 字典 / for 循环仍「学过」，while 循环仍「存疑」，未被误改 |
| 重复 done | 幂等：证据里产出路径只出现一次，状态仍「做过」 |
| 残留临时文件 | 无 |
