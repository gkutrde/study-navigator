# 【T-028】 作业点评（review 固定动作）

## 边界

任务卡「提交作业」：粘贴代码或填本地路径；**固定动作集加 review**，白名单 `{task, code}`；
代码 ≤8000 字符，超额**截断并注明**；LLM 按**验收方式**给评价 + 建议；留档含提交时间，**可多次**；
CLI 加 `review <时间戳> <文件>`。

## 修法

| 项 | 做法 |
| --- | --- |
| 新模块 | `src/review.py`：`prepare_code` / `build_review_messages` / `parse_review` / `review_code` |
| 截断 | `MAX_CODE_CHARS = 8000`；超额时**在代码尾部插入注明**（含原文长度），返回长度不超上限 |
| prompt | system 要求"**严格对照验收方式**"；user 带【任务目标】【验收方式】【学生提交的代码】 |
| 分段 | 明确要求 `【评价】…【建议】…` 两段；没有分区时整段当评价（`suggestion=""`），不报错 |
| 留档 | `append_review` 把「提交时间 + 评价 + 建议 +（可选）代码折叠块」追加到**目标任务块**（tmp + replace） |
| 可多次 | 用 `### 作业点评` 小节重复追加；`parse_reviews` 读回历次 |
| 双重把关 | 截断在 `append_review` 里**再做一次**——省得某条调用路径忘了裁而把整份代码塞进 tasks.md |
| CLI | `review <时间戳> <文件>`；文件不存在明确报错（不把路径当代码内容） |

## 实测

| 项 | 结果 |
| --- | --- |
| JSON 提交 | 200，返回两段；留档含提交时间 / 评价 / 建议 |
| 可多次 | 连交两次 → 点评条数 **2** |
| 超长代码 | 9000 字符 → 第 3 条 `truncated=True`，留档注明「已截断」 |
| 白名单 | 多给 `cmd` → **400**；缺 `code` → **400** |
| 页面 | 卡片含 `action="/action/review"` 与 `name="task"`/`name="code"`；历史点评显示在卡片内 |
| CLI | `review <时间戳> <文件>` 退出码 0，stderr 打印留档路径 |
| prompt 自检 | 桩函数断言 prompt 里**必须**含「页面能显示姓名」（验收方式），通不过就报错 |
