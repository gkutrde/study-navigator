# 【T-012】 本地只读看板（serve）

## 任务边界

- 所属模块：[[模块-命令行入口]]
- 对应需求/验收：[[04-任务与验收清单]] T-012（P2）；M3 本地看板
- 目标行为：serve 命令用标准库 http.server 绑定 localhost，把 profile/knowledge.md、tasks.md、syllabus.md 渲染成 HTML；**无任何写接口**；样式从简、留白给客户日后美化。
- 本任务不做：不做编辑/写回、不做鉴权（只绑本机）、不引入前端框架/构建链、不做图表。
- 前置依赖：T-007（已验收）。

## 验收示例

### 正常路径

- 给定：profile/ 下有画像与任务文件
- 当：python -m src.cli serve
- 则：浏览器访问 http://127.0.0.1:8765/ 可看到首页、画像、任务、地图页

### 异常或边界路径

- 给定：任何写请求
- 当：POST/PUT/DELETE/PATCH
- 则：405，返回「只读看板：不接受写请求」
- 给定：profile/ 下文件缺失
- 当：访问对应页面
- 则：页面提示「还没有 xxx：先运行相应命令生成」，不崩
- 给定：停服
- 当：对比文件哈希
- 则：全部文件字节不变、无残留 .tmp

## 实测结论

真端口起服 + 真 HTTP 请求：

| 请求 | 结果 |
| --- | --- |
| GET / | 200，1169 字节，6 个链接 |
| GET /knowledge | 200，4863 字节；h1×1、h2×11、统计表 4 行、列表项 27 |
| GET /tasks | 200，1515 字节；含「验收方式」 |
| GET /syllabus | 200，938 字节 |
| GET /nope | 404，带回首页链接 |
| POST/PUT/DELETE/PATCH / | 全部 405，返回「只读看板：不接受写请求」 |

只读保证：起服前后对 profile 下 3 个 .md 做 sha256 快照，**全部一致**；无残留 .tmp。
绑定地址确认为 127.0.0.1（build_server 默认 host），未对外网暴露。
