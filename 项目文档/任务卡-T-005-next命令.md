## 验收示例

### 正常路径

- 给定：画像有 ≥3 个已掌握知识点
- 当：python -m src.cli next
- 则：输出任务（目标/知识点/要点/验收方式），并追加到 profile/tasks.md

### 异常或边界路径

- 给定：已掌握知识点 < 3
- 当：执行 next
- 则：提示先补笔记/先确认状态，不出题

- 当：执行 next
- 则：带越界提示重试一次；仍越界则报错不出题、不留档

## 实测发现的四个问题（都是真实调用才暴露的）

1. **「存疑」不能算已掌握**：原实现只数总条数，会用没学会的知识点出题。已加「已掌握 ≥3」的门槛。
2. **next 没有 --provider**：没法强制走 Kimi 登录态。已补齐（与 distill 一致）。
3. **模型在 JSON 后继续写说明文字**（"希望这个任务对你有帮助"），按「整段必须是 JSON」解析会直接失败。已改为用 raw_decode 从第一个 { / [ 起取完整 JSON 值。
4. **模型会照抄 prompt 里带主题的写法**，把「列表（Python 基础）」当知识点名，被误判为越界。已加名称归一化（去「（主题）」后缀）＋ prompt 明确要求只写名称。
