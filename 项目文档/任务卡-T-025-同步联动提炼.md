# 【T-025】 看板「同步」按钮联动提炼

## 任务边界

客户两次踩坑：点了同步，画像不变（因为 `sync` 只落盘笔记、不提炼）。

- 模块：[[模块-命令行入口]] ｜ 验收：点一次按钮后画像即反映笔记变更；无变更时明确提示；提炼单篇失败不阻塞且报出篇目
- 不做：命令行 `sync` 保持**单职责**（只同步），联动只在看板

## 修法

| 项 | 做法 |
| --- | --- |
| 文案 | `ACTION_LABELS["sync"]`：**「同步并提炼」** |
| 联动 | 同步成功后接着跑 `distill --all`（复用 T-017 的 sha256 增量跳过，只处理变更篇） |
| 展示 | 结果分两段：`【同步】…（ROOT_DOC 备注）` + `【提炼】…` |
| 同步失败 | **不再提炼**（同步都没成功，提炼没意义），如实报错 |
| 提炼失败 | 不阻塞：同步已生效，追加一行「提炼失败：…」并把篇目原因带出来 |
| 无 JS/未配 ROOT_DOC | T-023 L-05 的行为原样保留（同步最近一篇 + 提示怎么改成全树） |
