- 所属模块：[[模块-命令行入口]]

- 目标行为：sync / import / distill / next / done 五个命令都能执行；参数非法退出码 2 并打印用法；凭证缺失明确报错（指出键名）退出码 1。

## 验收示例

### 正常路径

- 给定：任意命令 + 合法参数
- 当：执行命令
- 则：调用对应模块，输出结果，退出码 0

### 异常或边界路径

- 给定：缺参数或多余参数
- 当：执行任一命令
- 则：退出码 2，打印用法
- 给定：.env 缺飞书凭证
- 当：执行 sync
- 则：退出码 1，指出缺的键名（FEISHU_APP_SECRET），不发起请求
