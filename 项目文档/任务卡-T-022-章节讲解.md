# 【T-022】 章节讲解 explain

## 任务边界

- 所属模块：[[模块-书籍蒸馏导入]]、[[模块-任务生成]]
- 对应需求/验收：T-022 / F-10；「对画像中一个已掌握知识点 explain，输出讲解且注明出处章节；对地图中未学知识点 explain 可用；不在地图的点报错」
- 目标行为：CLI `explain <知识点>` + 看板「讲解」按钮（入参白名单加 `name`）；流程：地图定位 → 所属书/章 → 取参考文本（优先 `books/_src/` 原书；否则蒸馏稿对应章节）→ LLM 讲解；单次输入 ≤3000 字符，超额截断并注明；不在地图报错不瞎编。
- 前置依赖：T-021（已验收）；素材约定见 `books/_src/README.md`。

## 素材与实测发现

素材：7 本书 × 四件套（`.txt` / `.toc.md` / `.index.md` / `.code.md`），另有完整「前缀 ↔ 书名」对照表。

**实测踩到的三个格式差异**（我的单元测试最初按"想当然"的格式写，全被真实数据打回）：

| 差异 | 真实情况 | 处理 |
| --- | --- | --- |
| 区间写法 | 有四种：`（1266–2881）` 纯数字、`（L3990–4252）`、`（L69–L212）` 两侧带 L、`（L2748–L8603）✅` 带尾随符号 | 正则统一支持 `L?\d{2,}` + 可选尾随符号 |
| 章名语言 | 地图是中文「第 1 章 认识 HTML」，蒸馏稿是英文「第 1 章 · getting to know HTML」 | 名字比不中时按**章号**兜底（排除 `8.1` 这类小节标题） |
| 前缀怎么定 | 按书名猜**不可靠**：「C++ Primer」覆盖率 0.43、「鸟哥 Linux」**0.0**、「JavaScript DOM 编程艺术」0.11 | 改为在蒸馏稿 frontmatter **显式声明** `source: <前缀>`（7 份已补），书名猜测只作兜底 |
