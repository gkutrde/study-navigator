# 学习领航员 项目索引

## 一句话说明

为大一计算机新生把「飞书抄笔记」变成「学完就动手做」的闭环：读飞书笔记（含子文档）与 DeepSeek 书籍蒸馏稿 → 维护知识画像（我会什么）与知识地图（书还有什么该学）→ 生成贴合当前水平的动手任务 → 做完回写。

## 项目状态

- 当前阶段：开发（M1~M4、M6、M7 已完成；M2 已导入 7 份蒸馏稿并完成命名对齐；仅剩 M5 看板视觉待客户目检）
- 当前里程碑：M1 手动闭环演示（同步 → 提炼 → 出题 → 回写跑通一次）
- 项目负责人：客户本人
- 客户/使用方联系人：客户本人（自用项目）

## 新会话必读顺序

1. 本笔记：了解项目目标、当前阶段和任务入口。
2. [[01-需求与范围确认]]：确认要做什么、不做什么和如何验收。
3. [[02-系统架构]]：确认模块边界和依赖。
4. 与当前任务直接相关的模块笔记。
5. [[04-任务与验收清单]] 中当前领取的一项任务。
