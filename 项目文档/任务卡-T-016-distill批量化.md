# 【T-016】 distill 批量化

## 任务边界

- 所属模块：[[模块-知识画像]]
- 对应需求/验收：T-016；「全量跑一遍后画像覆盖所有非空笔记的知识点；重复跑一遍画像无重复条目」
- 目标行为：命令行 distill --all 提炼 notes/ 下**全部非空**笔记，可重复跑且幂等；看板「提炼知识点」按钮改为提炼全部并**逐篇汇总报告成败**，单篇失败不阻塞其余、明确报出失败篇目。
- 本任务不做：不做并发/断点续传、不自动重试单篇失败、不改提炼 prompt、不做增量（按 mtime 跳过未变笔记）。
- 前置依赖：T-004（已验收）。

## 复现与根因（可确认）

| 现状 | 后果 |
| --- | --- |
| CLI \`distill\` 只收一个文件参数（\`len(positional) != 1\` 即退 2） | 12 篇笔记要手工跑 12 次 |
| 看板 \`op_distill\` 只取 notes/ 里 **mtime 最新的一篇** | 画像只覆盖最新那篇，其余笔记的知识点从未进入画像 |

### 2. 最小实现

- 拟修改文件：src/distill.py（DistillBatch / discover_notes / distill_notes；透传 DistillError）、src/cli.py（distill --all、--notes-dir；看板 op_distill 改全量；capture 同时捕获 stderr）
- 最小改动说明：
  - \`discover_notes\`：notes/ 下 .md，跳过空文件，按文件名排序（结果稳定）
  - \`distill_notes\`：逐篇提炼；单篇异常只记进 failed，不打断整批
  - CLI：\`--all\` 与文件参数互斥；全部成功退 0，**有失败篇目退 1**（成功篇目仍写入画像，不整批回滚）
  - 看板 capture 改为**同时捕获 stderr**：否则页面只会显示「退出码 1」，看不到逐篇结果
- 不新增的复杂度：不做并发、不自动重试、不做增量、不改 prompt

不是批量逻辑的问题：该篇的 LLM 返回 JSON 有语法错误（\`Expecting ',' delimiter\`）。
批量逻辑按设计**没有回滚**——其余 11 篇照常写入，且失败篇目名称与原因都明确报出。
这也说明「单篇失败不阻塞其余」是真的生效了。
