# 【T-017】 全面审查

## 任务边界

- 所属模块：全部
- 对应需求/验收：T-017；「问题清单全部关闭（修复或明确不修的理由）；全量测试通过；六命令 + 看板端到端走一遍无错误」
- 审查维度：①错误路径 ②UX 简洁性 ③文档一致性 ④安全红线 ⑤效率

## 审查方法（可复核）

- **①错误路径**：脚本枚举 12 个异常输入（缺凭证 / 空串 / 坏链接 / 目录当文件 / 不存在文件 / 空目录 / 坏端口 / 缺端口值…），记录退出码与首行 stderr。
- **③文档一致性**：从各模块文档正则抽取 \`src/*.py\`、\`tests/*.py\`、命令表条目，与实现和磁盘逐项对账。
- **④安全红线**：用 sentinel 值构造 Credentials 检查 repr/页面泄漏；全仓扫 \`*.tmp\`。
- **⑤效率**：读 \`distill_notes\` 源码与签名，确认是否有进度输出与「跳过未变更」机制。
- **②UX**：据 ①的退出码/提示 + 实际命令序列推演新用户路径。
