## 修复记录

### L-01 新知识点回写断链（最严重）

**复现**：`done 一个画像里没有的点` → 退 1「画像里没有知识点…；可选：列表」，**不新增**。
后果：出题/讲解里遇到的新知识点，做完根本没法回写 → **核心闭环断裂**。

**修法**：`mark_done` 与 `set_level` 在「画像里没有这个点」时**新增条目**。
关键：只吞掉「没有知识点」这一种，**同名歧义（T-014）仍然报错**——那是真需要人工判断的。

| 路径 | 行为 |
| --- | --- |
| `done <新点> <产出>` | 新增条目，状态「做过」 |
| `done <新点> <产出> --recite "…"` | 新增条目，状态「输出」 |
| 看板状态表单填新名字 | 新增条目，状态按所选 |
| 归一化后撞名（歧义） | **仍报错**并列出候选 |

### L-02 重复出题

**复现**：`next` 不读 tasks.md；题库是确定性的 → 画像不变时**永远命中同一条**（实测真的是同一道 A-01）。

**修法**（两条路径都补）：
- 题库路径：`pick_assignment(..., already_given=…)`，跳过 tasks.md 里已出过的条目编号；
- LLM 路径：prompt 带上「已经出过这些任务，**不要重复**」+ 最近 5 个目标。

### L-03 explain 只认地图名

**修法**：先查地图 → 不行再把「画像名」经 T-021 对齐表**反查**成地图名 → 再查地图。
只反向映射，不编造：对齐表里没有的仍报错。

### L-04 planner.py 死代码

`_mapped_unmastered_in_book` 里 `return None` 之后还有 29 行不可达代码（我早前一次替换留下的）。
删除，并**加了一条 AST 测试**（`test_planner_has_no_unreachable_code_after_return`）扫描所有函数体内
return 之后是否还有语句，防止再犯。

### L-05 看板同步按钮只拉最新一篇

**修法**：`.env` 增可选 `FEISHU_ROOT_DOC`（`.env.example` 已文档化）：
- 配了 → 按钮同步**整棵树**，结果显示「已按 FEISHU_ROOT_DOC 同步整棵树：<token>」；
- 没配 → 仍同步最近一篇，但**提示语明确说清**：「把学习库根节点填进 .env 的 FEISHU_ROOT_DOC，以后点一次就同步整棵树」。
