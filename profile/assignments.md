# 经典课程实验题库

公开入门课程（CS50P / CS61A / MIT 6.0001 / 哈佛 CS50 等）的**题目骨架** + 知识点标签。
这里只放"要做什么"的骨架与验收方式，**不含任何课程原文与个人笔记内容**。

题库文件格式（`profile/assignments.md`）：

- 每条以 `## ` 开头，形如 `## A-01 标题`；
- 标题下一行必须是 YAML 元信息块：出处课程 / 标签 / 难度 / 新增点；
- 之后是**目标**、**实现要点**、**验收方式** 三个小节。

```yaml
course: 课程名（注明出处用）
tags: [知识点A, 知识点B]      # 必须是画像里真实存在的知识点名称
level: 入门 | 进阶
new_skill: 本次引入的唯一新知识点（可空）
```

匹配规则见 [[模块-任务生成]]：优先选题库中「已掌握标签最多、新点不超过 1 个」的一条；没有合适条目则回退 LLM 出题。

## A-01 个人名片页

```yaml
course: 哈佛 CS50（HTML 基础单元）
tags: [HTML 文档结构（DOCTYPE/head/body）, HTML 标签基础（双标签/单标签）, 标题与文本格式化标签, 图片 img 标签（src/alt/宽高）, 列表（ul/ol/li）]
level: 入门
new_skill: ""
```

**目标**：做一个单文件 `card.html`，展示一张"个人名片"：头像、姓名、一句自我介绍、兴趣列表。

**实现要点**：
1. 用 `<!DOCTYPE html>` + `<html><head><body>` 搭出完整文档结构，`<title>` 写你的名字；
2. 姓名用 `<h1>`，自我介绍用 `<p>`，需要强调的词用 `<strong>`；
3. 头像用 `<img>` 并**必须**写 `alt`；
4. 兴趣用无序列表 `<ul><li>`。

**验收方式**：浏览器打开后标题栏显示你的名字；页面从上到下依次是头像、姓名、介绍、兴趣列表；右键检查任意元素能看到正确的标签嵌套。

```yaml
course: 哈佛 CS50（HTML 基础单元）

```

**目标**：做一个 `schedule.html`，用表格展示一周 5 天、每天 4 节课的课程表。

**验收方式**：浏览器打开能数出 4 行 × 6 列（含表头行与节次列）；改动某个单元格文字后刷新页面，表格行列不错位。

## A-03 单页导航与锚点

```yaml
course: 哈佛 CS50（HTML 基础单元）
tags: [超链接 a 标签（href/target）, 列表（ul/ol/li）, 块元素与行内元素（div/span）, HTML 属性（class/id/style）]
level: 入门
new_skill: ""
```

**目标**：做一个 `nav.html`：顶部一条导航（3~4 个链接），点链接能跳到页面内的对应小节。

**实现要点**：
1. 每个小节用 `<div id="...">` 起一个锚点，导航链接写成 `<a href="#该 id">`；
2. 导航本身用 `<ul><li>` 排成一行；
3. 其中一个链接指向外部网站，用 `target="_blank"` 新标签页打开；
4. 用 `style` 属性把导航背景改成你喜欢的一种颜色。

**验收方式**：点导航每一项，页面都滚到对应小节；外部链接在新标签页打开；查看元素能确认 `id` 与 `href` 一一对应。

## A-15 命令行计算器

```yaml
course: 哈佛 CS50P（函数与异常单元）
tags: [列表]
level: 进阶
new_skill: 函数定义与 return
```

**目标**：写 `calc.py`：支持 `+ - * /` 四则运算，除零要给出友好提示。

**实现要点**：
1. 四个运算各写一个函数，统一接收两个参数并 `return` 结果；
2. 用一个"操作符 → 函数"的映射来分派（列表做不到，想想为什么）；
3. 除零时不要崩：捕获异常并提示"除数不能为 0"；
4. 输入非法操作符时提示可用操作符列表。

**验收方式**：`1+2=3`、`6/4=1.5`、`5/0` 提示友好且程序不退出；输入 `%` 时提示可用操作符。
