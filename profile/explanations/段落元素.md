# 段落元素 `<p>`

## 它是什么、为什么需要它

网页上的文字绝大多数是一段一段的，而 **段落元素 `<p>`（paragraph，段落的缩写）就是用来标记一段文字的基本 HTML 元素**。没有它，浏览器会把你的文字全连成一大块，读起来非常吃力。给每段文字包上 `<p>` 标签，浏览器就知道该在哪儿分段，还能自动在段落之间留出空隙。

## 最小例子

```html
<!DOCTYPE html>
<html>
  <head>
    <title>我的歌单</title>
  </head>
  <body>
    <h1>最爱的曲子</h1>
    <p>BT - Satellite：一首不错的慢节奏曲子。</p>
    <p>这段是另一首歌的点评。</p>
  </body>
</html>
```

把这段代码存成 `playlist.html`，用浏览器打开，你会看到两个段落之间自动空了一行——这个空隙是浏览器默认给 `<p>` 的样式，不需要你手动敲回车。

## 初学者最容易踩的坑

1. **用空 `<p></p>` 来"挤"出空白行。** 这是参考文本里特别提醒的错误做法。想拉开距离应该交给 CSS（比如 `margin` 属性），而不是堆积空段落，既脏又难以维护。

2. **忽略闭合标签 `</p>`。** HTML 中有少数元素可以不写结束标签（如 `<br>`），但 `<p>` 必须有头有尾。忘记闭合虽然有时浏览器能"猜对"，但会导致布局错乱，好习惯是成对书写。

> 补充说明：参考文本片段本身只展示了 `<p>` 的用法示例，并未给出 `<p>` 的完整定义性讲解；上述概念性说明是围绕这些示例作出的基础解释。
