## 一、任务卡

- **时间戳**：2026-09-27 00:32
- **目标**：写一个「班级点名册」命令行 Python 脚本：把人名存在列表里，逐个带序号打印出来
- **验收方式**：运行 python roster.py 后，终端能看到：一行标题、每个名字单独占一行且带递增序号（1. 张三 / 2. 李四 …）、最后一行总人数，全部对齐无误；如果循环体缩进错了会看到报错或格式混乱，可作为自查点
- **用到的知识点**：列表
- **新知识点**：for 循环（本次唯一的新点）

**实现要点**：
1. 新建文件 roster.py，先创建一个人名列表（如 5~8 个名字，用引号字符串）
2. 用 print 打印一行标题，如班级名
3. 用 for 循环遍历这个列表（今天唯一的新知识点：for x in 列表:），循环体里逐个打印人名
4. 改造循环体，让每一行输出「序号. 名字」的形式（提示：可用一个计数变量在循环里累加，序号从 1 开始）
5. 在循环结束后（注意缩进对齐！）再打印一行总人数，如「共 X 人」
6. 打印格式用 f-string 控制对齐：`print(f"{i}. {name}")`，避免 `print(a, b)` 产生的多余空格。
7. 总人数统计移到循环外只算一次：`print(f"共计 {len(class_name)} 人")`，并先运行自查：确认输出是 1.~4. 共 4 行名单、无重复无错位。
8. 用 `enumerate(class_name, start=1)` 替代手动维护 `i` 和 `i += 1`，更简洁也不容易在序号递增上出错。
9. 自查时故意把一个名字改成长度不同的字符串（如"小蓝"→"欧阳小明"），验证输出是否仍然对齐。

class_name =["小明","小红","小白","小蓝","小绿"]

    i += 1
