## 下一步任务

**目标**：写一个「班级点名册」命令行 Python 脚本：把人名存在列表里，逐个带序号打印出来

**用到的知识点**：列表
**新知识点**：for 循环（本次唯一的新点）

**实现要点**：
1. 新建文件 roster.py，先创建一个人名列表（如 5~8 个名字，用引号字符串）
2. 用 print 打印一行标题，如班级名
3. 用 for 循环遍历这个列表（今天唯一的新知识点：for x in 列表:），循环体里逐个打印人名
4. 改造循环体，让每一行输出「序号. 名字」的形式（提示：可用一个计数变量在循环里累加，序号从 1 开始）
5. 在循环结束后（注意缩进对齐！）再打印一行总人数，如「共 X 人」

**验收方式**：运行 python roster.py 后，终端能看到：一行标题、每个名字单独占一行且带递增序号（1. 张三 / 2. 李四 …）、最后一行总人数，全部对齐无误；如果循环体缩进错了会看到报错或格式混乱，可作为自查点

### 作业点评

**提交时间**：2026-09-29 01:18
**评价**：未通过验收。标题行和总人数行能正常输出，但核心的编号列表完全错误：你用了**双层 for 循环嵌套**，外层每取一个学生名，内层就把 1~5 全部打印一遍，实际输出是 4 个名字 × 5 个序号 = 20 行（1. 小明 / 2. 小明 / … / 5. 小明 / 1. 小红 …），既没有做到"每个名字单独占一行"，序号也没有按 1~4 递增。另外 `print(list_number,".",student_name)` 中逗号会自动加空格，输出是 `1 . 小明` 而不是验收要求的 `1. 小明`。`len_student = len(class_name)` 放在循环体内属于位置不当（虽然碰巧能算出正确总人数 5，但逻辑上应在循环外、且无需重复赋值 4 次）。
**建议**：1. 去掉内层循环，改用 `enumerate` 一步到位：`for i, name in enumerate(class_name, start=1):`，直接解决"序号递增"和"名字各占一行"两个问题。
2. 打印格式用 f-string 控制对齐：`print(f"{i}. {name}")`，避免 `print(a, b)` 产生的多余空格。
3. 总人数统计移到循环外只算一次：`print(f"共计 {len(class_name)} 人")`，并先运行自查：确认输出是 1.~4. 共 4 行名单、无重复无错位。

2. 用 `enumerate(class_name, start=1)` 替代手动维护 `i` 和 `i += 1`，更简洁也不容易在序号递增上出错。
