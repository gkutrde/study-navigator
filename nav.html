关于我

我是张三，正在从零学 HTML。

这个页面同时练四件事：超链接（href / target）、列表（ul / li）、块元素与行内元素（div / span）、HTML 属性（class / id / style）。

页面里凡是 像这样带浅蓝底的小段，都是 span——行内元素，不会把文字挤到下一行。

我会什么

目前写过带标题、段落、加粗、斜体、表格、图片、列表的练习页。

能自己搭出 <!DOCTYPE html> + html + head + body 的完整骨架。

刚学会给元素起 id，然后让导航链接精确跳到这个 id 所在的位置——也就是你现在看到的这个功能。

接下来学什么

先把链接与路径这一章收干净：相对路径、绝对路径、页面内锚点、新窗口打开。

然后进入 CSS：把 <style> 从 head 里拆出去存成 .css 文件，让结构（HTML）和呈现（CSS）彻底分开。

再往后是盒模型和布局，那时候才谈得上"把页面排得好看"。
