### 第一个C++程序
#### 基础程序
```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "hello world" << endl;
    return 0;
}
```
#### main函数
main函数是程序的入口，C++的程序不管有多少行代码，都是从`main`函数开始执行的，`main`函数也被叫做：**主函数**。`main`函数前面的`int`表示`main`函数执行结束的时候返回一个整型类型的值，而在`main`函数的最后写的`return 0;`正好前后呼应
- `main`函数是程序的入口
- `main`函数有且仅有一个
- 一个项目可以有多个`.cpp`文件，但只能有一个`main`函数（因为程序的入口只能有一个）
#### 字符串
在C语言中，使用单引号括起来一个字符字面值，比如`'1'`,`'a'`，使用**双引号**括起来多个字符表示一个字符串，比如`"abc"`，字符串可以有一个或多个字符，也可以没有任何一个字符，`""`表示空字符串
上面的代码中的`"hello world"`就是一个字符串，这类字符和字符串表示的方式在C++中也完全支持。
在C++的**STL**中又引入了`string`来表示字符串，功能更加强大，C语言不支持
#### 头文件
前面的代码中，写的`#include <iostream>`，就是头文件，头文件的名字叫：`iostream`，使用`#include <>`的形式进行包含，`iostream`文件中的`io`指的是输入（进入程序的信息，简单理解就是可以给程序输入数据）和输出（从程序中输出的信息，简单理解就是程序会打印数据到屏幕上）。
在`C++`程序中要完成输入和输出的操作会涉及到`iostream`文件中的多个定义，所以就要包含这个头文件。比如：代码中的`cout`是输出对象，就是用来完成数据输出的，就需要包含的头文件。
#### cin和cout初始
`cout << "hello world" << endl;`这句代码在上面的程序中是最重要的代码，其他所有的代码都是为了编写这句代码。
代码中的`cout`是标准输出流对象（针对控制台，也就是屏幕），其实还有标准输入流对象`cin`。
`cout`是告诉程序把后面双引号中的内容打印到标准输出设备（屏幕）上，双引号中的内容是可以替换的。
```cpp
#include <iostream>
using namespace std;

int main()
{
    int num;        //num是一个空间，可以存放一个整数
    cin >> num;        //获取标准输入
    cout << num << endl;//对获取到的结果标准输出
    return 0;
}
```
1. `cin`和`cout`是全局的流对象，`cin`负责输入数据，`cout`负责输出数据。
2. `endl`是C++中一个特殊的操作符，效果是换行和刷新缓冲区，使用时必须包含在`iostream`头文件。
3. `<<`是流插入运算符，和`cout`配合使用，`>>`是流提取运算符，和`cin`配合使用，两者容易混淆
4. 使用C++输入输出更方便，不需要`printf/scanf`输入输出那样，需要手动控制格式，C++的输入输出可以自动识别变量类型
```cpp
#include <iostream>
using namespace std;

int main()
{
    float score = 0;        
    cin >> score;    //直接读取的就是浮点数    
    cout << score;    //直接输出的就是浮点数
    return 0;
}
```
#### 名字空间
`using namespace std;`这句代码的意思是：使用名字空间`std`（名字空间也叫命名空间）。
在C++中，变量、函数和类型都是大量存在的，这些变量、函数和类的名称如果都存在与全局作用域中，可能会导致很多冲突。使用`名字空间`的目的是对标识符的名称进行隔离，以避免命名冲突或名字污染，`namespace`关键字的出现就是针对这种问题的。
`std`是C++标准库的名字空间，C++将标准库的定义实现都放到了这个命名空间中，当我们需要使用标准库中的内容时，就需要加上：`using namespace stdl;`当有了这句代码的时候，表示命名空间`std`中信息都是可见和可用的，比如：`cin`、`cout`、`endl`等。
命名空间也是根据需要自己定义的
当然直接使用`using namespace std;`是一种更加简单粗暴的做法，直接这样使用，就意味着后续再`std`这个名字空间中的各种定义都可以直接使用，但往往我们只使用部分，所以名字空间其实也可以这样使用：
```cpp
#include <iostream>
int main()
{
   std::cout << "hello world" << std::endl;
   return 0;
}
```
#### 注释
C++里主要有两种形式：单行注释`//`和多行注释`/*  */`
注释本来是对代码进行解释的文字，要放在代码中，但是又无需编译。注释是给程序员自己看的，编译器会忽略注释，基于注释是被编译器忽略的这个特点，在代码中有些代码不再需要的时候也会使用注释屏蔽。
**单行注释**：指的是当前行不参与编码和运行
**多行注释**：指的是被包含在内的多行不参与编译和运行

所谓**“类型”**，就是相似的数据所拥有的共同特征，编译器只有知道了数据的类型，才知道怎么操作数据。

```cpp
char            //character的缩写
```
在键盘上可以敲出各种字符，如：`a`，`q`，`@`等，这些符号都被称为**字符**，字符是用单引号括起来的，如：`'a'`，`'q'`，`'@'`。为了能说明这些字符，给他们抽象出了一种类型，就是**字符型**，C语言中就是`char`。
**ASCII编码**
我们知道在计算机中所有的数据都是以二进制的形式存储的，那这些字符子在内存中分别以什么二进制存储呢？如果我们每个人都给这些字符串编一个二进制序列，这个就叫做**编码**。为了方便大家相互通信，不造成混乱，后来美国国家标准会（ANSI）出台了一个标准ASCII编码，C语言中的字符串就遵循了ASCII编码的方式。
我们不需要记住所有的ASCII码表中的数字，使用时查看就可以，不过最好能掌握几组特殊的数据：
- 字符`A~Z`的ASCII码值从65~90
- 字符`a~z`的ASCII码值从97~122
- 对应的大小写字符的ASCII码值的差值是32
- 数字字符`0~9`的ASCII码值从48~57
- 换行`\n`的ASCII值是：10
- ASCII码值从0~31这32个字符是不可打印字符，无法在屏幕上观察
```cpp
#include <iostream>
using namespace std;

int main()
{
    char ch1 = 'q';
    cout << ch1 << endl;
    char ch2 = 113;
    cout << ch2 << endl;
    
    return 0;
}
```
#### 整型
整型类型是对所有整数的抽象，为了能对所有整数形成统一的类型标识，就有了整型；
在C和C++中，整型被分为四大类：`short`，`int`，`long`，`long long`。
```cpp
short//短整型
int    //整型
long    //长整型
long long//更长的整型
```
#### 浮点型
浮点对于所有的实数（小数）的抽象，为了能对视数进行统一的类型标识，就有了浮点型。
浮点型有三种：
```cpp
float        //单精度的浮点型
double        //双精度的浮点型
long double    //更长的双精度的浮点型
```
在C/C++中小数的书写形式：
```cpp
3.14    //编译器会默认识别为double类型

1.23e5+10
```

C++中有一种类型叫：`bool`（布尔类型），布尔类型的变量可以是`true`或`false`，这种类型的变量专门用来表示真或假的。当然在C和C++中，0表示假，非0表示真，有时候不用`bool`类型也可以表达相同的逻辑。
```cpp
bool
```
#### signed与unsigned
`singned`和`unsigned`关键字修饰**字符型和整型**类型的。
`signed`关键字，表示一个类型带有正负号，包含负值；比如：温度、银行存款。
`unsigned`关键字，表示该类型不带有正负号，只能表示零和正整数，比如年龄。
有了`signed`和`unsigned`的修饰，字符和整型类型其实可以更加丰富，可以有以下这些：
```cpp
//字符型
char
signed char    //有符号的字符型
unsigned char  //无符号的字符型

//短整型
short [int]
[signed] short [int]    //有符号的整型
[unsigned] short [int]  //无符号的整型

//整型
long [int]
[signed] int    //有符号的整型
[unsigned] int  //无符号的整型

//长整型
long [int]
[signed] long [int]    //有符号的长整型
[unsigned] long [int]  //无符号的长整型

//更长的整型
long long [int]
[signed] long long [int]    //有符号的
[unsigned] long long [int]  //无符号的
```
对于`int`类型，默认是带有正负号的，也就是说`int`等同于`signed int`。
由于这是默认情况，关键字`signed`一般都省略不写，但是写了也不算错。
`int`类型也可以不带正负号，只表示非负整数，这时就必须使用关键字`unsigned`声明变量。
变量声明为`unsigned`的好处是，同样长度的内存能够表示的最大整数值，增大了一倍。
`unsigned int`里面的`int`可以省略
#### 数据类型的长度
每一种数据类型都有自己的长度，使用不同的数据类型，能够创建出长度不同的变量，变量的长度不同，存储的数据范围也有所差异
##### sizeof操作符
`sizeof`是一个关键字，也是操作符，专门是用来计算数据类型的长度的，单位是字节。
`sizeof`操作符的操作数可以是类型，也可以是变量名或表达式，`sizeof`的操作数如果不是类型，是表达式的时候，可以省略后面的括号。
```cpp
sizeof（类型）
sizeof 表达式
```
`sizeof`的计算结果是`size_t`类型的，`size_t`指的是无符号整数（该类型包含了所有可能的`unsigned int`，`unsigned long`，`unsigned long long`等类型，具体取决于编译器）。
```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    cout << sizeof(a) << endl;
    cout << sizeof a << endl;
    cout << sizeof(int) <<endl;
    return 0
}
```
##### 各数据类型长度
```cpp
#include <iostream>
using namespace std;

int main()
{

    cout << sizeof(long) << endl;
    cout << sizeof(long long) << endl;
    cout << sizeof(float) << endl;
    cout << sizeof(double) << endl;
    cout << sizeof(long double) << endl;
    return 0
}
```

#### typedef

`typedef`使用的基本语法形式：

```cpp
typedef 旧类型名 新类型名;
```

```cpp
typedef unsigned int unit;
```

### 变量与常量
#### 变量的创建
类型是可以用来**创建变量**的。
变量创建的格式：
```cpp
date_type name;
```
```cpp
int age;
char ch;
double weight;
```
变量命名的规则：
- 变量名只能由字母、数字和下划线组成，且必须以字母或下划线开头。
- 变量名不能以纯数字开头，也不能包含特殊字符，如空格、连字符等。
- 变量名不能以语言的关键字，如int、char、if等。
- 变量名应具有意义，有助于理解变量的含义和用途。
- 变量名应该简短明了，避免使用过长的名称。
- 变量名应区分大小写。
#### 变量初始化
变量在创建的时候就给一个初始值，就叫初始化。
```cpp
int age = 13;
char cn = 'w';
double weight = 48.0;
unsigned int height = 100;
```
#### 变量的分类
- **全局变量**：在大括号外部定义的变量就是全局变量
全局变量的使用范围广，整个工程中想使用，都是有办法使用的。
- **局部变量**：在大括号内部定义的变量就是局部变量
局部变量的使用范围比较局限，只能在自己所在的局部范围内使用的
```cpp
#include <iostream>
using namespace std;

int globe = 2023;    //全局变量

int main()
{
    int local = 2018;    //局部变量
    cout << local << endl;
    cout << globe << endl;
    return 0;
}
```
如果局部变量和全局变量名字相同：
```cpp
#include <iostream>
using namespace std;

int n = 1000;    //全局变量

int main()
{
    int n = 10;    //局部变量
    cout << n << endl;
    return 0;
}
```
当局部变量和全局变量同名时候，局部变量优先使用。
- 全局变量：全局变量通常在定义时就被初始化，如果没有明确指定初始值，它们通常会被初始化为0.
- 局部变量：局部变量通常不会自动初始化。它们需要在使用之前明确的赋值或初始化。如果没有初始化，它们的值将是未定义的，使用未初始化的局部变量可能会导致不可预测的行为或运行错误，因此**局部变量建议初始化**。
#### 常量
常量就是不能改变的值，通常我们会使用三种常量：
- 字面常量
- `#define`定义常量
- `const`定义常量
##### 字面常量
**整型常量**：`100，-5，0，0x123`整型常量一般可以写成10进制、8进制、16进制。
10进制数字，如：`6、7、33、435`
8进制数字，一般是数字0开头的，比如：`012、016`
16进制数字，一般是0x开头的数字，比如：`0x123、0xFF`
**字符常量**：`'a'`
**浮点型常量**：`3.14`，`1E6`（科学计数法的形式）
##### #define定义常量
```cpp
#define 常量名 内容
```
```cpp
#include <iostream>
using namespace std;

#define M 100
#define CH 'x'
#define PI 3.14159

int main()
{
    cout << M << endl;
    cout << CH << endl;
    cout << PI << endl;
    return 0;
}
```
这里定义的M、CH、PI都是常量，可以直接使用，但是不能被修改。
使用`#define`定义常量的时候是不关注类型的，只关注常量的名字叫啥，常量的值是啥，编译器在处理这种常量的时候就是直接替换，再出现常量名的地方，通常替换常量的内容。
##### const定义常量
C++中还可以使用`const`来定义常量，这种常量会有具体的类型。比`#define`定义常量更加严谨。
```cpp
const 类型 常量名字 = 常量值;
```
```cpp
#include <iostream>
using namespace std;

const double PI = 3.14159;
int main()
{
    int r = 0;
    cin >> r;
    cout << "周长：" << 2*PI*r << endl;
    cout << "面积：" << PI*r*r << endl;
    return 0;
}
```
习惯上，这种常量的名字一般会大写，而普通变量的名字不会全大写，这样可以做一个区分。
- 增加了程序的可读性，`PI`比`3.1492`更加容易理解和书写、使用。
- 增加了程序的可维护性，如果改变常量的值，只要在定义的部分修改，使用的地方也就随之改变了，做到了“一改全改”的效果。
- 常量是不能修改的，当然`const`定义的常量自然也是不能修改。
### 算术操作符
#### 算术操作符
在写代码时候，一定会涉及到计算。为了方便计算，提供了一系列操作符，其中一组操作符叫：**算术操作符**。分别是`+ - * / %`，这些操作符都是**双目操作符**。
**易错点**：
- `/`除法操作符，除数不能为0，如果除数为0，程序会崩溃的。
- `%`取模操作符的计算结果是两个操作符进行除法运算后的余数。
- 取模操作符的操作数只能是整型，不能是浮点型。
#### 浮点数的除法
```cpp
#include <iostream>
using namespace std;

int main()
{
    float x = 6 / 4;
    cout << x << endl;    //1
    
    float  y = 6.0 / 4;
    cout << y << endl;    //1.5
    return 0;
}
```
上面的示例中，尽管变量`x`的类型是`float`，但是`6 / 4`得到的结果是`1`，而不是`1.5`。原因是在于整数的除法是整除，只会返回整数部分，丢弃小数部分。
如果希望得到浮点数的结果，**两个运算数必须至少有一个浮点数**，这时就会进行浮点数除法。
#### 负数的取值
- 负数也是支持取模的，但是负数求模结果的正负号是第一个运算数的正负号决定。
#### 数值溢出
```cpp
#include <iostream>
using namespace std;

int main()
{
    char a = 'Z';
    char b = a + 'Z';
**    **cout << int(b) << endl; //-76 
    return 0;
}
```
以char类型为例，char的数值范围在-128~127，当字符相加超过最大值后，打印出来的结果会变为负数
### 赋值操作符
#### 连续赋值
赋值操作符可以连续赋值，如：
```cpp
int a = 3;
int b = 5;
int c = 0;
c = b = a + 3;    //连续赋值，从右向左依次赋值的。
```
虽然支持这种连续赋值，但是写出的代码不容易理解，建议还是拆开来写，这样方便观察代码的执行细节。
```cpp
int a = 3;
int b = 5;
int c = 0;
b = a + 3;
c = b;
```

在写代码时，我们经常可能对一个数进行自增、自减的操作，如下代码：
```cpp
int a = 10;

a = a - 2;
```
这样的代码C++中提供了更加方便的写法：
```cpp

a -= 2;
```

### 类型转换
在使用C/C++写代码的过程中，不同的数据类型进行混合运算时，或者赋值时等号两边的数据类型不统一时，都会发生类型转换，这时候就需要根据转换规则转换成合适的类型。
#### 混合运算时的类型转换
字符、整数、浮点数可以进行混合运算，这种情况下首先要将不一致的数据类型进行转换，类型统一后才能进行计算。
这里边一般涉及两类转换，整型提升和算数转换。
**整型提升**：表达式中的`char`和`short`类型一定会先转换成int类型，然后参与运算。
**算数转换**：表达式中出现下面任意两种类型的值进行计算的时候，要先将较下面的类型转换为另一种类型才能计算。
```cpp
long double
double
float
unsigned long int
long int
unsigned int
int
```
#### 赋值时类型转换
当赋值操作符两端的数据类型不一致的时候，这时就需要类型转换，这种类型转换也是隐式自动发生的。
转换规则如下：
5. `float`和`double`赋值给`int`，直接**截断**小数部分，保留整数部分。
```cpp
int a = 3.14;
```
6. 较小的类型转换为较大的类型，直接转换，值不变。
7. 较大的值类型转换为较小的类型，一般会发生截断，按照较小类型的长度，保留地位数据给较小的类型。
这些转换都是隐式自动发生的，有些编译器会报警告，写程序的人并没有感知到，也不需要操心细节。
#### 强制类型转换
在C/C++中也会有强制类型转换，根据实际的需要将某一数据类型转换为指定的数据类型，强制转换时临时转换的，不影响变量本身的类型。语法如下：
```cpp
(类型名) 表达式
```
例如：
```cpp
double d = 3.14;
int a = (int)d;
```
上面的代码是将`double`类型的3.14转换为`int`类型的值，赋值给`a`
### 单目操作符
前面介绍的操作符都是双目操作符，都有两个操作数，除此之外还有一些操作符只有一个操作数，被称为单目操作符。如`++、--、+(正)、-(负)`都是单目操作符。
#### ++和--
`++`是一种自增的操作符，又分为前置`++`和后置`++`，`--`是一种自减的操作符，也分为前置`--`和后置`--`
- 前置`++`或者后置`++`，都是让操作数自增1的
- 前置`--`或者后置`--`，都是让操作数自减1的
##### 前置++和后置++
```cpp
//案例1
int x =10;
int a = ++x;    //++的操作数是x，是放在x前面的，就是前置++
cout << x << " " << a << endl;

//案例2
int x =10;
int a = x++;    //++的操作数是x，是放在x后面的，就是后置++
cout << x << " " << a << endl;
```
**后置先使用再+1，前置先+1后使用**
##### 前置--和后置--
```cpp
//案例1
int x =10;
int a = --x;    //--的操作数是x，是放在x前面的，就是前置--
cout << x << " " << a << endl;

//案例2
int x =10;
int a = x--;    //--的操作数是x，是放在x后面的，就是后置--
cout << x << " " << a << endl;
```
**后置先使用再-1，前置先-1后使用**
#### +和-
这里的`+`是正号，`-`是负号，都是**单目操作符**。
运算符的`+`对正负值没有影响，是一个完全可以省略的运算符，但写了也不会报错。
```cpp
int a = +10;    //等价于 int a = 10;
```
运算符`-`用来改变一个值的正负号，负数前面加上`-`就会得到正数，正数前面加上`-`就会得到负数。
```cpp
int a = 10;
int b = -a;
int c = -10;
cout << b << c <<endl;    //这里的b和c都是-10

int a = -10;
int b = -a;
cout << b << endl;    //这里的b是10
```

### getchar 和 putchar
`getchar()`和`putchar()`是属于C语言的库函数，C++是兼容C语言的，所以C++中只要正确包含头文件也可以正常使用这两个函数。
#### getchar()
函数原型如下：
```cpp
int getchar (void)
```
`getchar()`函数返回用户输入的一个字符，使用时不带有任何参数。
程序运行到这个命令就会暂停，等待用户从键盘输入，等同于使用`cin`和`scanf()`方法读取一个字符。
它的原型定义在头文件`<cstdio>`。
```cpp
#include <iostream>
#include <cstdio>

using namespace std;

int main()
{
    int ch;
    ch = getchar();
    cout << ch << endl;
    cout << (char)ch << endl;
    return 0;
}
```
`getchar()`不会忽略起首的空白字符，总是返回当前读取的第一个字符，无论是否为空格。
如果读取失败，返回常量`EOF`，由于`EOF`通常是`-1`，所以返回值的类型通常要设置为`int`，而不是`char`。
如何让`getchar()`函数读取失败，返回`-1`呢？其实需要在输入字符之前，直接按`Ctrl+z`就可以。
```cpp
#include <iostream>
#include <cstdio>
using namespace std;

int main()
{
    int ch;
    ch = getchar();
    cout << ch << endl;
    return 0;
}
//按住Ctrl+z，返回-1
```
`getchar()`通常和`putchar()`是一对，配合使用。
#### putchar()
函数原型如下：
```cpp
int putchar(int character);
```
`putchar()`函数将它的参数字符输出到屏幕，它的原型定义在头文件`<cstdio>`。
```cpp
#include <cstdio>

int main()
{
    int ch = 0;
    ch = getchar();
    putchar(ch);
    
    return 0;
}
```
操作成功时，使用`putchar()`返回输出的字符，否则返回常量`EOF`。
### scanf 和 printf
`scanf()`和`printf()`是属于C语言的库函数，C++是兼容C语言的，所以C++中只要正确包含头文件也可以正常使用这两个函数。

```cpp
#include <cstdio>
```

```cpp
int mian()
```

```cpp
}
```
##### 占位符
`printf()`可以在输出文本中指定占位符。
所谓的“占位符”，就是这个位置可以用其他值代入。
```cpp
#include <cstdio>

int main()
{
    printf("There are %d apples\n",3);
    return 0;
}
```
上面示例中，`There are %d apples\n`是输出文本，里面的`%d`就是占位符，表示这个位置要用其他值来替换。
占位符的第一个字符一律为`%`，第二个字符表示占位符的类型，`%d`表示这里插入的必须是一个整数。
`printf()`的第二个参数就是替换占位符的值，上面的例子是整数`3`替换`%d`，执行后的输出结果是`There are 3 apples`。
常见的占位符除了`%d`，还有`%s`表示代入的是字符串。
```cpp
#include <cstdio>
int main()
{
    printf("%s will come tonight\n","zhangsan");
    return 0;
}
```

```cpp
#include <cstdio>
int main()
{

    return 0;
}
```
上面的示例中，输出文本`"%s says it is %d o'clock"`有两个占位符，第一个字符串占位符是`%s`，第二个是证书占位符`%d`，分别对应`printf()`的第二个参数（`lisi`）和第三个参数（`21`）。执行后的输出是`"lisi says it is 21 o'clock"`。

##### 格式化输出
`printf()`可以定制占位符的输出格式。
###### 限定宽度
`printf()`允许限定占位符的**最小宽度**。
```cpp
#include <cstdio>
int mian()
{
    printf("%5d\n",123);//输出为“  123”
    return 0;
}
```
上面的示例中，`5%d`表示这个占位符的宽度至少为5位。如果不满5位，对应的值的前面会添加空格。
输出的值**默认是右对齐**，即输出内容前面会有空格；如果希望改成左对齐，在输出内容后面添加空格，可以再占位符的`%`的后面插入一个`-`号。
```cpp
#include <cstdio>
int main()
{
    printf("%-5d\n",123);    //输出为“123  ”
    return 0;
 }
```
对于小数，这个限定符会限制所有数字的最小显示宽度。
```cpp
#include <cstdio>
//输出“  123.450000”
int main()
{
    printf("%12f\n",123.45);
    return 0;
}
```
上面的示例中，`%12f`表示输出的浮点数最少要占据12位。由于小数的默认显示精度是小数点后6位，所以`123.45`输出结果的头部会添加2个空格。
###### 限定小数位数
输出小数时，有事希望会限定小数的位数。举例来说，希望小数后面只保留两位，占位符可以写成`%.2f`。
```cpp
#include <cstdio>
//输出Number is 0.50
int mian()
{
    printf("6.2f\n",0.5);
    return 0;
}
```
上面的示例中，`%6.2f`表示输出的字符串最小宽度为6，小数位数为2。所以，输出字符串的头部有两个空格。
最小宽度和小数位数这两个限定值，都可以用`*`代替，通过`printf()`的参数传入。
```cpp
#include <cstdio>
int main()
{
    prinf("%*.*f\n",6,2,0.5);
    return 0;
}
```
上面示例中，`%*.*f`的两个星号通过`printf()`的两个参数`6`和`2`传入。
#### scanf
`scanf()`函数原型如下：
```cpp
int scanf(const char * format,...);
```
##### 基本用法
`scanf()`函数用于读取用户的键盘输入。
程序运行到`scanf()`这个语句时，会停下来，等待用户从键盘输入。
用户输入数据、按下回车键后，`scanf()`就会处理用户的输入，将其存入变量。
请看下面代码：
```cpp
#include <cstdio>

int main()
{
    int i = 0;
    scanf("%d",&i);    //&取地址操作符
    printf("%d\n",i);
    return 0;
}
```
它的第一个参数是一个格式字符串，里面会放置占位符（与printf（）的占位符基本一致），告诉编译器如何解读用户的输入，需要提取的数据是什么类型。这是因为C语言的数据都是有类型的，`scanf()`必须提前知道用户输入的数据类型，才能处理数据。
它的其余参数就是存放用户输入的变量，格式字符串里面有多少个占位符，就有多少个变量。
上面示例中，`scanf()`的第一个参数`%d`，表示用户输入的应该是一个整数。`%d`就是一个占位符，`%`是占位符的标志，`d`表示整数。第二个参数`&i`表示，将用户从键盘输入的整数存入变量`i`。

### cin 和 cout
`cin`是`C++`中提供的标准输入流对象，一般针对的是键盘输入的字符流，使用`cin`来进行数据的提取，`cin`一般是和`>>`（流提取运算符）配合使用的。`cin`的功能和`scanf`是类似的。
`cout`是`C++`中提供的标准输出流对象，一般针对控制台的窗口，也就是将数据以字符流的形式，也就是将数据以字符流的形式输出到控制台窗口上显示。`cout`一般是和`<<`（流插入运算符）配合使用的。`cout`的功能和`printf`是类似的。

  我们写程序的时候，经常需要处理数据，不管是什么类型的数据都是以**字符流**的形式输入和输出的，也就是不管在键盘上输入什么类型的数据，还是将程序中的各类型的数据输出显示到控制台屏幕上，都是以字符流的形式处理的。
`cin`和`cout`的输入输出非常方便，不需要手动控制格式，能够**自动识别变量类型**。
