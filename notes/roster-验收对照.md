## 一句话结论

**验收方式 7 项：6 PASS / 1 FAIL。唯一硬伤是点号后少一个空格——`1.小明` 应为 `1. 小明`。**

## 表 A：验收方式原文（这一栏才决定过不过）

| # | 验收方式原文 | 结果 | 证据（实跑） |
|---|---|---|---|
| 1 | 一行标题 | PASS | 首行 `自定义班级` |
| 2 | 每个名字单独占一行 | PASS | 名单行数 = 5，与列表长度一致 |
| 3 | 带递增序号（1. 张三 / 2. 李四 …） | PASS | `1.小明 … 5.小绿`，无跳号无重复无错位 |
| 4 | 格式 `1. 张三` | **FAIL** | 五行全部为 `n.名字`，点号后无空格 |
| 4补 | 名字与列表一一对应 | PASS | `['小明','小红','小白','小蓝','小绿']` |
| 5 | 最后一行总人数 | PASS | 末行 `共计5人` |
| 6 | 循环体缩进自查点（不会报错/格式混乱） | PASS | 无 `IndentationError`/`SyntaxError`；`共计` 只出现 1 次、顶格未被吞进循环 |

### 档 0 —— 只求过验收（改 1 个字符）
